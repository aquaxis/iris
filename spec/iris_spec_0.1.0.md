# IRIS 言語仕様書 v0.1.0

---

**IRIS** (アイリス: Immutable RTL Implementation Standard)

ハードウェア記述言語の言語仕様書

---

## 目次

### 第0章 [概要](./00_overview.md)
IRIS言語の思想、主要な特徴、SystemVerilogとの比較を説明します。

### 第1章 [字句構造](./01_lexical_structure.md)
文字セット、識別子規則、コメント構文、予約語（54語）、リテラル、演算子・区切り子を定義します。

### 第2章 [型システム](./02_type_system.md)
プリミティブ型（bit, bool, clock, reset）、複合型（enum, struct, union）、配列型、ジェネリクス、型推論・型変換規則を説明します。

### 第3章 [モジュール定義](./03_module_definition.md)
モジュール構文、ポート宣言、信号宣言、インスタンス化、外部モジュール連携について説明します。

### 第4章 [組み合わせ論理](./04_combinational_logic.md)
`let`宣言と`comb`ブロックによる組み合わせ回路記述、完全割り当てチェック、match式、ループ検出を説明します。

### 第5章 [順序論理](./05_sequential_logic.md)
`sync`ブロックによる順序回路記述、クロックエッジ指定、リセット処理、クロックドメイン交差（CDC）を説明します。

### 第6章 [FSM](./06_fsm.md)
`fsm`ブロックによる有限状態機械の記述、状態定義、遷移記述、エンコーディング指定を説明します。

### 第7章 [インターフェース](./07_interface.md)
`interface`定義、ビュー（initiator/target/monitor）、接続規則、継承・コンポジションを説明します。

### 第8章 [演算子](./08_operators.md)
算術演算子、ビット演算子、比較演算子、論理演算子、ビット選択・スライス、連結・レプリケーション、優先順位規則を説明します。

### 第9章 [メモリ](./09_memory.md)
`mem`キーワードによるメモリ宣言、RAM/ROM推論、ポート構成、初期化方法を説明します。

### 第10章 [検証機能](./10_verification.md)
テスト構文、アサーション、カバレッジ、シミュレーション制御を説明します。

### 第11章 [パッケージシステム](./11_package_system.md)
パッケージ定義、公開制御（pub）、インポート規則、プロジェクト構成（iris.toml）を説明します。

### 第12章 [アトリビュート](./12_attributes.md)
合成アトリビュート、階層制御、リソース制御、タイミング制御、デバッグアトリビュートを説明します。

### 第13章 [エラーメッセージ](./13_error_messages.md)
エラーコード体系（O0xxx〜O6xxx）、警告一覧、警告制御を説明します。

### 第14章 [移行ガイド](./14_migration_guide.md)
SystemVerilog → IRIS変換ガイド、よくあるパターンの対応表、移行チェックリストを提供します。

### 第15章 [文法定義](./15_grammar.md)
EBNF形式による完全な文法定義を提供します。

### 第16章 [サンプルコード集](./16_examples.md)
基本的なカウンタ、パラメータ化FIFO、AXI-Liteスレーブ、FSM例などのサンプルコードを提供します。

### 第17章 [用語集](./17_glossary.md)
IRIS言語仕様書で使用される技術用語の定義を提供します。

### 第18章 [よくある質問（FAQ）](./18_faq.md)
IRIS言語に関するよくある質問と回答を提供します。

### 第19章 [チュートリアル](./19_tutorial.md)
初心者向けのステップバイステップガイド。基本的なモジュールからFSMまでを段階的に学びます。

### 第20章 [IDE連携ガイド](./20_ide_guide.md)
VS Code、Neovim、Emacs、IntelliJ IDEAでのIRIS開発環境のセットアップ方法を説明します。
