# iris2sv CLI Reference

## Overview

`iris2sv` is a command-line tool for transpiling IRIS hardware description language to SystemVerilog.

## Installation

```bash
# From npm (once published)
npm install -g iris2sv

# From source
git clone <repository>
cd iris2sv
pnpm install
pnpm build
```

## Basic Usage

```bash
# Compile a single file
iris2sv input.iris

# Compile multiple files
iris2sv file1.iris file2.iris

# Compile with glob patterns
iris2sv "src/**/*.iris"

# Compile all files in a directory
iris2sv src/
```

## Options

| Option | Short | Description |
|--------|-------|-------------|
| `--output <dir>` | `-o` | Output directory for generated files |
| `--watch` | `-w` | Accepted but not implemented; the option has no effect |
| `--verbose` | `-v` | Verbose output |
| `--strict` | | Treat warnings as errors |
| `--check` | | Check only, do not generate output |
| `--no-color` | | Disable colored output |
| `--dry-run` | | Show what would be done without writing files |
| `--auto-output-wire` | `-a` | Auto-generate internal wires for output ports that are read |
| `--version` | | Show version number |
| `--help` | `-h` | Show help message |

## Examples

### Basic Compilation

```bash
# Compile a single file (output: input.sv in same directory)
iris2sv input.iris

# Compile to specific output directory
iris2sv input.iris -o build/

# Compile multiple files to output directory
iris2sv "src/*.iris" -o dist/
```

### Verbose Mode

```bash
# Show detailed compilation progress
iris2sv -v input.iris
```

Output:
```
Compiling: input.iris
[iris2sv] Parsing input.iris...
[iris2sv] Building symbol table for input.iris...
[iris2sv] Analyzing input.iris...
[iris2sv] Generating input.iris...
  -> input.sv

Compilation succeeded: 1 file(s) compiled, 0 warning(s).
```

### Check Mode

```bash
# Check for errors without generating output
iris2sv --check input.iris
```

### Strict Mode

```bash
# Treat warnings as errors
iris2sv --strict input.iris
```

### Dry Run

```bash
# Preview what would be generated
iris2sv --dry-run input.iris
```

## Output Format

By default, `iris2sv` generates SystemVerilog files with:
- `.sv` extension (replacing `.iris`)
- Header comment indicating generated file
- Same directory as input (unless `-o` specified)

### Example Output

Input (`counter.iris`):
```iris
mod counter(
    in  clk: clock,
    in  rst: reset,
    in  enable: bool,
    out count: bit[8],
) {
}
```

Output (`counter.sv`):
```systemverilog
// Generated by iris2sv
// Do not edit manually

module counter (
  input  logic       clk,
  input  logic       rst,
  input  logic       enable,
  output logic [7:0] count
);
endmodule
```

## Exit Codes

| Code | Description |
|------|-------------|
| 0 | Success |
| 1 | Compilation error or file not found |

## Error Messages

### Parse Errors

Syntax errors in IRIS source files are reported with line and column numbers:

```
error: Expected '}' but found 'EOF'
  --> input.iris:5:1
   |
 5 | }
   | ^
```

### Semantic Errors

Type errors and semantic issues include detailed explanations:

```
error[E0001]: Type mismatch in assignment
  --> input.iris:10:5
   |
10 |     y = x;
   |     ^^^^^ expected bit[8], found bit[16]
```

### Warnings

Non-fatal issues are reported as warnings:

```
warning[W0001]: Unused input port 'enable'
  --> input.iris:4:5
   |
 4 |     in enable: bool,
   |        ^^^^^^
```

## Configuration

Currently, `iris2sv` does not support configuration files. All options must be specified via command-line arguments.

Future versions may support:
- `iris2sv.config.json` configuration file
- Custom output formatting options
- Plugin system for custom transformations

## Programmatic Usage

For programmatic usage, import the `Compiler` class directly:

```typescript
import { Compiler } from '@iris2sv/cli';

const compiler = new Compiler({
  strict: false,
  verbose: false,
  checkOnly: false,
});

const result = compiler.compile(sourceCode, 'input.iris');

if (result.success) {
  console.log(result.output);
} else {
  console.error(result.diagnostics);
}
```
